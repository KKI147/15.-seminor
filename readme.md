# 테트리스 UI 개편 기획서

## 개요

기존 테트리스의 레이아웃을 개선하여 더 많은 정보를 제공하고,  
시각적으로 균형 잡힌 UI를 구성합니다.

---

## 변경 사항

### 1. HOLD 패널 높이 축소 (약 30%)

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| HOLD 표시 영역 | 패널 전체 높이 (`appH`) | 상단 30% 영역에만 표시 |
| 블록 스케일 | `0.62` | `0.55` (작아진 영역에 맞게 축소) |
| 중심 Y 좌표 | `appH / 2 + 6` | `HOLD_ZONE_H / 2` (상단 30% 중앙) |

- `HOLD_ZONE_H = appH * 0.30` 로 정의 — 이 높이 안에서 HOLD 블록을 수직 중앙 정렬

---

### 2. 우측 NEXT 미리보기 패널 추가

#### 레이아웃 변경

```
[변경 전]
┌──────────┬──────────────────────┐
│  HOLD    │                      │
│  패널    │    게임 보드 (10×20) │
│ (좌측)   │                      │
└──────────┴──────────────────────┘

[변경 후]
┌──────────┬──────────────────────┬──────────┐
│  HOLD    │                      │  NEXT    │
│  패널    │    게임 보드 (10×20) │  패널    │
│ (좌측)   │                      │  (우측)  │
└──────────┴──────────────────────┴──────────┘
```

#### 앱 크기 변경

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| `appW` | `HOLD_PANEL + BOARD_PAD*2 + COLS*BLOCK` | `HOLD_PANEL + BOARD_PAD*2 + COLS*BLOCK + NEXT_PANEL` |
| `NEXT_PANEL` | 없음 | `5 * BLOCK + 24` (HOLD_PANEL과 동일) |

#### NEXT 큐 관리 방식

- 7-bag 방식 유지
- `nextTypeFromBag()` 를 직접 pop 하는 대신, **bag를 미리 5개 채워놓고 peek** 하는 방식 도입
- `peekNext(count)` 함수 추가: bag를 소비하지 않고 앞으로 나올 타입 목록을 반환
- `spawnPiece()` 에서만 실제 pop 수행

#### NEXT 패널 렌더링

- `nextGfx` Graphics 객체 추가 (zIndex: 8)
- `nextLabel` Text 추가 ("NEXT", zIndex: 9)
- `drawNext()` 함수 추가
  - 최대 5개 블록을 세로로 나열
  - 각 블록마다 일정 간격(`NEXT_ITEM_H`)을 두고 배치
  - 블록 스케일: `0.55`
  - 첫 번째(다음) 블록은 약간 크게 표시 (스케일: `0.65`)
- `renderAll()` 에 `drawNext()` 추가

## 구현 상세

### 상수 목록 (현재)

```js
const HOLD_PANEL  = 5 * BLOCK + 24;  // 좌측 HOLD 패널 너비 (174px)
const NEXT_PANEL  = 5 * BLOCK + 24;  // 우측 NEXT 패널 너비 (174px)
const NEXT_COUNT  = 5;               // NEXT 미리보기 개수
const BOARD_PAD   = 8;               // 보드 안쪽 여백
const PANEL_GAP   = 30;              // 패널 ↔ 게임판 사이 간격 (흰색 갭 공간)
const HOLD_ZONE_H = appH * 0.30;     // HOLD 표시 영역 높이 (전체의 30%)
```

### 레이아웃 구조 (현재)

```
┌──────────┬──┬──────────────────────┬──┬──────────┐
│  HOLD    │  │                      │  │  NEXT    │  ← 위: 5번째(흐림)
│  (30%만) │G │    게임 보드 (10×20) │G │  4번째   │
│          │A │                      │A │  3번째   │
│  [빈공간]│P │                      │P │  2번째   │
│  배경 없음│  │                      │  │  1번째(다음, 크고 밝음)│
└──────────┴──┴──────────────────────┴──┴──────────┘
                                              ↑ NEXT 라벨
```

> `GAP` = `PANEL_GAP` (14px)

### 함수 목록

| 함수 | 역할 |
|------|------|
| `ensureBagSize(n)` | bag 크기가 n 미만이면 추가 셔플 보충 |
| `peekNext(count)` | bag를 **소비하지 않고** 다음 N개 타입 반환 |
| `drawHold()` | HOLD 블록을 HOLD_ZONE_H(30%) 영역 중앙에 렌더링 |
| `drawNext()` | 5개 블록을 세로 배열 (맨 아래 = 다음 블록) |
| `drawPanelAndBorder()` | HOLD 배경(30% 높이), NEXT 배경(전체 높이) 렌더링 |
| `renderAll()` | 전체 렌더 순서: Panel → Board → Ghost → Active → Grid → Hold → Next |
